# Jeremy Lubanga - Portfolio

## Problem Statement

Jeremy's current portfolio lacks modern visual appeal, has limited animations, minimal mobile optimization, and doesn't showcase creativity effectively. The existing design uses basic colors, standard typography, and minimal motion - resulting in a generic appearance that doesn't differentiate him as a creative developer.

## Solution

A comprehensive rebuild of the portfolio with:

- Playful, motion-rich animations (springs, rubber bands, floating elements, 3D tilts)
- Modern cyberpunk neon aesthetic (dark background with cyan/magenta/lime green glows)
- Staggered asymmetrical hero with animated floating background elements
- Interactive project cards with 3D tilt, orbiting tech icons, and fullscreen modals
- Glass morphism navbar with spring physics slide-in animation
- Background combining gradient mesh, floating particles, and noise texture
- Bruno Ace SC Google Font for modern typography
- Floating 3D contact cards with staggered entrances
- Mobile-first responsive design ensuring mobile works perfectly
- Preserved dark/light mode toggle

## Tech Stack

- Vanilla HTML/CSS/JavaScript (no frameworks)
- Bruno Ace SC Google Font
- CSS Custom Properties for theming
- Vanilla JS animations

## Getting Started

1. Open `portfolio.html` in a browser
2. Toggle between dark and light themes
3. Hover over project cards for 3D tilt effects
4. Check out animations - smooth scroll, entrance, micro-interactions

## Features

- **Hero Section**: Staggered asymmetrical layout with floating photo and animated background elements
- **Project Cards**: 3D tilt on hover, bouncy entrance, orbiting tech icons, fullscreen modals
- **Navigation**: Glass morphism navbar with blur effects and spring slide-in animation
- **Contact Section**: Floating 3D cards with staggered entrances
- **Background**: Animated gradient mesh + particles + noise texture
- **About Me**: New section highlighting background and skills
- **Animations**: Mix of spring, rubber band, and liquid blob easing
- **Mobile**: Full responsive design with mobile-first approach

## Theme Toggle

Click the sun/moon icon in the navbar to switch between dark and light themes. Your preference is saved automatically.
